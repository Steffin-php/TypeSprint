TypeSprint

TypeSprint is a minimal typing speed test that helps you measure and improve your typing speed and accuracy. Choose a difficulty level, race against the clock, and track your WPM, accuracy, and errors in real time.

Live Website: https://type-sprint-t35k.vercel.app/

Features
🎯 Three Difficulty Levels — Easy, Medium, and Hard, each with unique passages and time limits

⏱️ Live Timer — Countdown starts on your first keystroke

⚡ Real-Time Stats — Live WPM, accuracy percentage, and error count as you type

✅ Instant Feedback — Correct characters turn white, mistakes are highlighted in red, with a blinking cursor showing your position

📊 Results Summary — Final WPM, accuracy, and error breakdown after each sprint

🔀 New Passage — Shuffle through a large pool of unique passages per difficulty

🔁 Quick Restart — Press Tab anytime to instantly start a new sprint

📱 Responsive Design — Works smoothly on desktop and mobile

Tech Stack
HTML, CSS, JavaScript
No backend or database required — fully client-side

How It Works

Select a difficulty level (Easy, Medium, or Hard)
Start typing the displayed passage — the timer begins automatically
Watch your WPM, accuracy, and errors update live
Finish the passage or let the timer run out to see your final results
Click New Passage or press Tab to try again
